# 变更历史

## [0.1.2] - 2026-11-10

- 文档：插件详情页的效果图不再露出本机凭据路径（不暴露本机用户名），图注与截图实际内容一致。
- 文档：仓库不再收录内部 devops 调研笔记和用不到的 pnpm-lock.yaml；标题上限说明改为「装到本机 profile 时写入」。

## [0.1.1] - 2026-11-10

- 首个版本：会话行悬停点一下，用该会话自己的模型把整段对话概括成一行标题并直接重命名；标题会被钉住，之后的自动标题不再覆盖它。
- 可在插件页开启「devops 编号前缀」：会话里命中 devops 链接时，标题改为「编号 平台标题｜短总结」。
- 冷会话（不在内存里）也能用：先按需读取日志，改名时由官方会话服务恢复该会话。
