# 变更历史

## [0.2.0] - 2026-11-19

### 新增

- 点通知卡片直接切到出这条通知的会话：浏览器通知在点击回调里调 `ctx.uiWorkspace.openSession(sessionId)`，和侧边栏点一行完全一样。
- Host 用 `osascript` 发的兜底卡片没有点击回调（点它只会把 App 提到前面），改为页面记住这张卡片指向的会话，在窗口下一次被激活时切过去；10 分钟后不再跟随，避免普通回到窗口时被拽到旧会话。
- 每条会话一张卡片（`tag` 按会话区分），两条会话同时完成不会互相覆盖、也不会点错会话。

### 修复

- 「需要你回答 / 需要你审批」的通知不再没有会话：从请求携带的 agent 取会话 id 与标题，点卡片同样能定位。
- 通知权限改为按页面记录（每条 SSE 流带 `page` 标识）：关掉的标签页不再让兜底永久失效，也不会因为某个页面能弹通知就重复发 `osascript` 卡片。
- 会话不在当前页面目录里时（另一个窗口刚建出来的会话），先刷新会话列表再重试一次，点卡片不再没反应。
- `__dshTaskNotifyTest()` 之前注册时机写错、实际装不上，现在控制台可用。

### 调整

- 兜底卡片的标题带上「任务完成 · 会话标题」这样的前缀，与浏览器卡片一致；等回答 / 等审批的卡片也带会话标题。
- README 增加「点通知会跳到哪个会话」一节；验证命令改用当前端口，并支持 `?sessionId=` 验证跳转。
