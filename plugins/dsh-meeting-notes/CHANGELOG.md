# 变更历史

## [0.1.1] - 2026-11-26

### 新增
- 首个版本：左侧栏「会议纪要」入口 + 整页。点「开始记录」同时录系统声音（对方）和麦克风（我），两条轨同一个时钟、同一个文件，天然区分「我 / 对方」。
- 边录边转写：每 20 秒切一块，先掐掉块首尾静音，再交本机 whisper.cpp（large-v3-turbo）逐块识别，实时原文标好时间戳和说话人。
- 停止后自动补齐剩余块、调 DSH 当前模型按模板生成纪要（标题 / 摘要 / 会议信息 / 议题与讨论 / 结论与决定 / 待办表格 / 风险与未决 / 关键原话），录音转 m4a 归档。
- 历史列表：状态徽标（录制中 / 转写中 / 生成纪要 / 已完成 / 中断 / 失败）、一句话摘要、按标题与原文关键词搜索。
- 详情页：纪要 / 原文 / 录音三个标签；点原文任意一句跳到录音对应时间；导出纪要或原文 Markdown；改标题；删档案。
- 导入官方转写：把钉钉闪记 / 腾讯会议 / Teams 的转写整段粘进来替换原文，本机自动版留底，可来回切换。
- 中断可补完：DSH 被强杀留下的录制，音频不丢，点「补完」续上转写与纪要。
- 首次使用引导：页面内安装 whisper.cpp、下载语音模型（带进度），装好一次之后全程离线。
- 音频只在本机；只有生成纪要时的转写文字会发给 DSH 当前模型。

### 调整
- 生成纪要时过滤 whisper 在静音段编出的固定句子（「请不吝点赞…」「字幕由…」这类），避免污染原文和纪要。
- 录音归档默认把 wav 转成 96k AAC 的 m4a，1 小时约 40MB；`keepWav` 可改为保留原始 wav。
