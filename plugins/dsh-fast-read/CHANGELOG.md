# 变更记录

## [0.1.3] - 2026-11-23

### 修复

- **大书图谱显示 0 节点**：`graph.json` 超过工作区文件读取的单页 5000 行上限时会被截断、解析失败；现在按页读完整个文件再解析（《乡下人的悲歌》的图谱有 5643 行）。
- **节点标签挡住点击**：标签不再拦截指针事件，点圆点或按 Tab + Enter 都能选中节点。

### 调整

- 图谱节点较多时（>150）默认折叠低权重节点，但保留核心节点的邻居，避免出现一张没有边的星图；折叠数量在右下角标出。
- 标签只画给最重要的十几个节点，其余悬停或选中时出现。
- 选中节点时聚焦其邻域（其余淡出），力导向参数与边的对比度按大图调过。

## [0.1.2] - 2026-11-23

### 修复

- **正文交不到模型手里**：`book_read` 只渲染「第 N 章共多少字」，章节正文没有进上下文；现在正文随结果返回，并在还有下一段时附上续读参数。
- **全角字符与标点写法不同导致误拒收**：校验两边共用同一套归一化（NFKC、全角引号/问号、`——` 与 `—`、`……` 与 `...` 折叠为同一形态），正确的引用不再因为输入差异被拒。
- **超长单行切不开**：没有换行的正文（扫描版 OCR、粘贴的长文）现在按句末标点再按字符切，保证没有抽取单元超过 6000 字。
- **并发写丢数据**：同一本书的 `record` 串行执行，索引写入串行，临时文件名加随机后缀。
- **加密与坏档**：ZIP 加密条目、DRM EPUB、密码保护 PDF 给出明确错误，不再把密文或空白页当正文。
- **无效脑图落盘**：指向不存在节点的脑图不再写盘，进度也不会被标成完成。
- **客户端白屏**：`graph.json` 被手改成非法结构时，图谱降级为空状态，不再让整个标签页被错误边界吞掉。
- **客户端卡顿**：轮询只在四个文件真的变了时才更新状态，图谱不会每 2.5 秒重算布局。
- **切书串数据**：旧请求的结果不会盖到新选的书上；换书会清空上一本的选中节点、折叠状态与缩放。
- **抽屉被裁**：图谱高度与详情抽屉的高度约束改对，矮窗口下「跳到原文」也在可见区域内。
- **键盘可用**：图谱节点与脑图行可聚焦，Enter/空格选中；缩放改用非 passive 滚轮监听。

## [0.1.1] - 2026-11-20

- 首个版本：导入 EPUB/PDF/TXT/DOCX，逐章抽取带原文出处的概念与关系，右侧栏输出导读、脑图、关系图与知识图谱。

## 0.1.0

### 新增

- 导入 EPUB / PDF（文字版与扫描版 OCR）/ TXT / Markdown / HTML / DOCX / 粘贴文本，按章节切分并存进工作区 `.dsh-books/`。
- 四个工具：`book_import`（解析与切章）、`book_read`（章节窗口）、`book_record`（写入并校验）、`book_state`（进度与抽取协议）。
- 出处校验：每个节点、每条关系都必须带原书引文，逐条比对，对不上就拒收并回传最接近的原文。
- 右侧栏「速读」标签页：导读、脑图、图谱（力导向）、关系图、出处五个视图，可全屏。
- 同名概念跨章自动合并，权重取最大、出处累积。
- 章节摘要与进度可断点续跑。

### 说明

- MOBI / AZW3 暂不支持。
- 微信读书的「大众划线」层不在本版本，后续版本单独加。
